# 🚀 UC4 – TypeScript

Projeto desenvolvido como parte da unidade curricular **UC4**, com exercícios e exemplos em **TypeScript** para praticar:

- Tipagem forte
- Funções e tuplas
- Classes e Objetos
- Encapsulamento
- Herança
- Interfaces
- Abstração

Este repositório contém diversos arquivos com exemplos e exercícios aplicados.

Arquivo com uma **classe que representa uma conta bancária** com métodos públicos:

- `sacar(valor: number)`
- `consultarSaldo()`
